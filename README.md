# CollabBoard

A full-stack Kanban-style team task board.

## Overview

CollabBoard lets teams organize work into boards, lists, and cards, with live updates across all connected clients.

## Tech Stack

- **Frontend:** React
- **Backend:** Node.js / Express
- **Database:** MongoDB / Mongoose
- **Real-time:** Socket.io
